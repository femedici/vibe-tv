# Design Context

Audience: Felipe using his Samsung 50-inch living-room TV with a remote; local browser for review.
Use: resume access to existing apps, switch PS5 HDMI2, organize favorites and change skins.
Tone provided by user: fluid, clean, personal. Direction: restrained cinema interface, spacious TV-safe controls, strong typography, supplied PlayStation art as the major visual. Dark default with all five requested skins. No fabricated film art/watch history.
Technical constraints: Chromium 76; native CSS without modern unsupported color syntax; reuse inherited font with license rather than introducing a dependency. No costly blur or looping motion. Focus feedback via transform/opacity and reduced motion fallback.
